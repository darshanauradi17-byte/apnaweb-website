BrandX Web

A request system for local business websites

A business owner fills in a form, gets a request ID and can follow progress on a tracking page. The site owner manages every request from a private dashboard.

  • Request form with validation and a request ID on submit
  • Public tracking page that shows status only, never contact details
  • Owner dashboard to search, filter, update status and call or WhatsApp the customer
  • Leads stored in a JSON file, so no database is needed to start
  • Protected owner login: hashed password, HttpOnly session cookie, CSRF protection and rate limits on every form
  • Optional AI assistant that answers visitors' questions by text or voice
